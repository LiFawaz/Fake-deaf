# Fake-deaf

Appear muted and deafened to other people while your real microphone and audio stay live.

## Install

Copy this URL into Revenge's plugin installer:

`https://LiFawaz.github.io/Fake-deaf/fake-deafen/`

## Use

- Join a voice channel.
- Run `/fake` to toggle Fake-deaf on or off.
- Or open the plugin's **Configure** settings and use **Fake Deafen Active**.
- **Broadcast as Muted** and **Broadcast as Deafened** independently control what other people see.

The setting change sends an updated voice state when you're connected to voice. Discord client changes can affect whether this works on every build.
