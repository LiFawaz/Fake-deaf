# Fake-deaf

Fake-deaf lets you appear muted and deafened to other people in a Discord voice call while keeping your microphone and audio working on your side.

## Install

Copy this link and paste it into Revenge's plugin installer:

`https://LiFawaz.github.io/Fake-deaf/fake-deafen/`

## Setup

1. Install Fake-deaf using the link above.
2. Open Revenge's **Plugins** menu.
3. Find **FakeDeafen** and open its **Configure** menu.
4. Turn on **Fake Deafen Active** when you want to use it.
5. Use **Broadcast as Muted** and **Broadcast as Deafened** to choose what other people see.

You don't need a slash command. Everything is controlled from the plugin's Configure menu. Turn **Fake Deafen Active** off when you want to go back to normal.
