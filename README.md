# Fake-deaf

Fake-deaf makes Discord show you as server deafened and muted while your mic and audio stay live.

## Setup

1. Add the plugin using this link: https://LiFawaz.github.io/Fake-deaf/fake-deafen/
2. Open Revenge and go to your plugins.
3. Find **Fake-deaf** and open its **Configure** menu.
4. Turn it on or off from there.

There aren't any slash commands for this plugin. You control it from the plugin's Configure menu.
